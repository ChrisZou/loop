# Loop 审阅

Loop 是一个 Mac 原生 App。`loop review <方案.md>` 打开一个审阅窗口，用户在原文上选字批注、写总体意见、勾选待办，点「提交」后命令结束，标准输出就是整理好的反馈。一轮一轮来：写方案 → 用户批注 → 按反馈改 → 再审，直到用户不再提意见。

## 1. 写方案

把要审的内容写成一个 `.md` 文件。放在当前项目里合适的位置（如 `docs/`），或者临时目录都行；第一个 `# 标题` 会作为窗口标题，没有标题就用文件名。

写成**方便逐条批注**的样子，用户是选中原文写意见的：

- 每个决定、每个步骤单独一行或一个列表项，别把几件事塞进一大段。
- 需要用户拍板的选项写成任务列表 `- [ ] 方案 A：…`，用户直接点勾；勾选变化会随反馈回来。
- 把拿不准的地方明确写成问题，不要藏在叙述里。
- 篇幅只放需要审的内容，背景一两句带过。

Loop 能渲染：标题、粗体、列表、`- [ ]` 任务列表、行内代码、代码块、引用、GitHub 表格、图片。

- 图片 `![说明](图片/架构.png)` 的相对路径按 **方案文件所在目录** 解析，路径有空格写成 `![说明](<图片/架构 图.png>)`；也支持绝对路径和 http(s) 图片。图表、截图、界面草图放进去，用户能直接对着图批注。
- 普通链接 `[文字](url)` 和斜体不渲染，会原样显示，直接写网址即可。

## 2. 发起审阅

```sh
loop review 方案.md
```

这条命令会**一直阻塞**到用户点「提交」或关掉窗口，常常要十几分钟甚至更久：

- 你的环境能后台运行命令、结束时通知你（如 Claude Code 的 `run_in_background`），就后台运行，然后停下等通知，不要轮询、不要 sleep。
- 只能前台运行的，把命令超时设到允许的最大值。
- 不要用 `open`、AppleScript 或界面自动化去打开 Loop、粘贴内容；就用这条命令。
- 可以同时开多份审阅，各自独立。

发起后在对话里告诉用户一句：已经打开审阅窗口了。

## 3. 读结果

| 退出码 | 含义 | 怎么做 |
| --- | --- | --- |
| 0 | 用户点了「提交」，标准输出是反馈 | 按下面处理 |
| 1 | 用户没提交就关了窗口（stderr：`loop: 未提交`） | 不要自动重开。在对话里问用户是要继续审、改了再审，还是先不审了 |
| 64 / 66 | 用法错误 / 文件读不到或为空 | 检查路径和内容后重试 |
| 69 | 找不到 Loop.app | 让用户构建：`cd <loop 仓库>/mac && ./build-app.sh && ln -sf "$PWD/bin/loop" ~/.local/bin/loop` |

命令不存在（`command not found`）时同样提示用户安装，别自己找替代方案。

**用户认可**：输出正好是 `我看过了这版方案，没有修改意见，可以按这版继续。`，表示没有任何批注就提交了。审阅结束，按这版继续往下做。

**有反馈**：格式如下，各部分没有就不出现。

```text
以下是我对你方案的逐条反馈，请据此修改出下一版：
（「附图」是本机上的图片文件，请打开查看。）

1. 原文：
   > 用户选中的原文（已去掉 Markdown 符号；图片写成 [图片：说明]）
   意见：用户的意见
   附图：/Users/…/attachments/…/xxx.png

2. 原文：
   > …
   意见：…

待办的勾选状态改为：
- [x] 方案 A：…
- [ ] 方案 B：…

总体意见：…（多条时是编号列表，也可能带附图）
```

- 按原文定位到方案里的位置，逐条处理；条目按原文顺序排列。
- `附图：` 后面是本机图片路径，**一定要打开看**，用户常用截图说明问题。
- 勾选状态是用户对 `- [ ]` 选项的决定，下一版里照此更新（选中的保留并展开，没选的删掉或注明不做）。
- 只有 `意见`、没有明确改法的，按你的判断改；真有两种以上合理理解、改错代价大的，在下一版里写成 `- [ ]` 选项让用户选，而不是在对话里停下来问。

## 4. 改完再审

1. 直接修改同一个文件，出下一版。每一条意见都要落实，不能悄悄跳过；不同意的，在对应位置写明理由。
2. 在对话里用几行列出这版按反馈改了什么（第几条 → 怎么改的）。
3. 再次运行 `loop review` 同一个文件，进入下一轮。

内容一改就是新的一轮，窗口里是干净的；如果文件没改又发起审阅，用户上次没提交的批注会自动恢复。

一直循环，直到用户提交时没有任何意见（见上面的认可文本），或者用户在对话里说可以了、不用再审。
